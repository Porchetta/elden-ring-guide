# Elden Ring Guide

개인용 엘든 링 빌드별 진행 가이드 저장소입니다.

## 구조

- `index.html` : 빌드 선택 홈
- `builds/dark-moon-greatsword/` : 암월의 대검 빌드 가이드
- `assets/css/` : 공통 스타일
- `assets/images/` : 지도/NPC/아이템 이미지

## 운영 방식

각 빌드는 독립 섹션으로 관리합니다. 빌드별로 Phase 문서를 두고, 실제 플레이 중 나온 질문/수정사항은 해당 Phase의 `notes.md`에 기록한 뒤 가이드 본문에 반영합니다.
